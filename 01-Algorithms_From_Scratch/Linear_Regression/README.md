This folder contains the manual implementation of Linear Regression.

## Files
* `linear_regression_scratch.ipynb`: The main notebook containing the code for Gradient Descent and Normal Equation.
* `Income.csv`: Small dataset used for training (Features: Age, Experience | Target: Income).

## How to run
Open the notebook and run all cells. Ensure `Income.csv` is in the same directory.
